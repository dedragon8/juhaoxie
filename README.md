# 剧好写

用直觉写作。一款为中文剧本写作和 AI 视频创作做的 Mac 应用。

[免费下载 Mac 版](https://github.com/dedragon8/juhaoxie/releases/latest) · [观看中文实机演示](media/juhaoxie-demo-zh.mp4)

## 视频简介

写剧本时，我经常刚想好一句台词，就得停下来切格式。于是自己做了「剧好写」。视频里从新建剧本、编辑人物开始，按 Tab 选段落类型，写完人名按回车就能接着写台词。括注和短剧里的 OS 也可以直接写进文稿。

同一场戏可以切换好莱坞、常见中文、优化中文和短剧四种排版。在分场视图里调整顺序，场号会跟着更新。做 AI 视频时，可以在 Prompt 工作区框选一段原文，为它设计镜头、关联参考图，之后想改某个镜头，也能找到对应的那段戏。

## 安装

1. 在上方下载页的 **Assets** 中选择 `Juhaoxie-0.6.16-Mac-AppleSilicon.zip`。此版本适用于搭载 Apple 芯片的 Mac。
2. 解压，把「剧好写.app」拖入「应用程序」。
3. 打开剧好写，在剧本库新建剧本，或打开内置演示开始体验。

此版本采用本地签名，未经 Apple 公证。下载页附有 SHA-256 校验文件。
