剧好写 0.6.16
用直觉写作

适用于 Apple Silicon Mac。macOS 26 及更新系统使用原生 AppKit 玻璃工具栏与目录；较旧系统使用兼容界面。文稿编辑器沿用现有功能。
将“剧好写.app”放入“应用程序”。使用新版前退出旧版，已有本地剧本库继续保留。

开始写作
首次打开的剧本库包含可编辑的《落水狗》简短对白节选演示，原作与排版示意在资料页中分别注明；仅添加一次，删除后不再自动出现。
已有用户可在剧本库点击“添加演示剧本”；重复点击不会覆盖已编辑的演示。
首次打开可查看新手引导；也可在“设置 → 关于与版权 → 新手引导”重新查看。
在剧本库新建剧本，双击打开；右键可删除或显示文件位置。
Tab 选择段落格式，上下键选择，Enter 确认。人物后回车进入对白；括注自动生成括号，回车继续对白。
⌘1 人物，⌘2 描述/动作，⌘3 对白，⌘4 括注；其余快捷键在设置中查看和修改。⌘0 添加场景，⌘F 查找替换，⌘Z 撤销。
软件内及跨剧本复制保留段落格式。文稿中 ⌘A 全选文稿；普通输入框保持自身的全选行为。

剧本格式
设置 → 剧本格式：好莱坞格式、常见中文、优化中文、短剧。
常见中文：按场编号，标题为“场次 地点 时间 内外景”；描述与对白分段、段首空两字，人物名后接对白，不加短剧的集数及△标记。
格式参照中国电影艺术研究中心公开电影剧本要求，并保留 A4 和默认苹方字体；不是所有制作公司的统一标准。
切换格式保留已有文字和字体，应用于当前剧本并作为新剧本默认值；其他剧本不受影响。
短剧支持人物后的 OS、VO 自动识别、大写与括号，以及字幕、空镜、闪回等标注。

整理与保存
目录按幕展开；幕管理可拖动分配场景。分场可拖拽调整顺序。
目录中双击场景名称可直接输入新名称。单击场景卡片定位到场景开头，浏览文稿时目录跟随高亮。右键可重命名、隐藏或删除；隐藏及删除前确认。
本地自动保存。版本记录可保存、重命名、删除版本，也可打开独立副本。
.jhwrite 为可编辑专用文件，无密码，便于跨电脑传输；格式本身不等于加密。
预览可导出 A4 PDF 或 Word；Word 自动换行分页可能与 PDF 不同。
剧本资料可填写人物介绍和故事梗概，并选择在封面与文稿之间加入资料页。

触控板
双指平移，捏合缩放。轻微斜向滚动的横向分量降低但不锁定，到达上下限位时轻微回弹。
点击右下角百分比适配窗口，保持当前阅读位置；工作区切换记住文稿位置。

Prompt
设置 → 外观 → Prompt 工作区可关闭或打开入口；已有镜头和草稿保留。
框选原文创建镜头；点击镜头高亮关联原文。镜头按原文位置排序。
人物、内容、镜头、光线、声音、参数和连续性可编辑，完整 Prompt 在下方实时生成，支持复制全文。
镜头可单独或批量隐藏、删除。导出可选 PDF、Word、TXT，或每镜头一个 TXT 的 ZIP。

接入 Agent
把应用放在固定位置并保持运行。在设置 → 接入 Agent 打开“接入Agent”。
打开后点击“复制给 Codex”或“复制给 Claude”，粘贴到相应客户端，让它配置 MCP 并读取剧本标题验证。展开同一页的“Agent 接入教程”可查看手动配置，或将接入权限从只读改为可编辑。
首次配置可能需批准或重新打开会话；只有实际读取成功才表示已连接。
普通剧本自动接入。全局授权在重启后保留，可随时关闭。安全区剧本禁止 Agent 与 iCloud 访问。
iCloud 协作已关闭，本版以本地文件为主。

文稿字体：在写作工具 → 文稿字体中搜索本机字体，可分别设置选中文字和整份文稿。安装新字体后点击“刷新字体”。跨电脑传输保留字体名称，缺少字体时暂用苹方；字体文件不随剧本传输。

Prompt 参考图：在镜头设计顶部上传 JPG、PNG 或 WebP，在字段中输入 @ 选择参考图。图片经本地缩小后随 .jhwrite 保存，不附带原始图片文件。已授权的 Agent 可读取当前剧本的参考图；安全区仍禁止接入。
